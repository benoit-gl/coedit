# Third-party notices

Coedit Local is a new implementation. No TreeWriter source code has been copied into this repository.

The application uses open-source dependencies whose license texts and attribution are distributed by their respective package managers and release tooling. Principal runtime components include:

- Tauri — Apache-2.0 OR MIT
- React — MIT
- Tiptap and ProseMirror — MIT
- Yjs — MIT
- DOMPurify — Apache-2.0 OR MPL-2.0
- SQLite — public domain

Before distributing a release, generate a complete dependency license inventory from the committed JavaScript and Rust lockfiles and include the corresponding notices in the package.
